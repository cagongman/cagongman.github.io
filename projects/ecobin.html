Ecobin


프로젝트 개요

Ecobin은 공공데이터 기반 지도 시각화와 리워드 구조를 결합한 위치 기반 탐색형 모바일 서비스입니다. MapKit 위에 카테고리별 오브젝트를 배치하고, 사용자 위치 추적과 보상 피드백을 연결하는 클라이언트 흐름을 구현했습니다.

도메인은 공공 서비스였지만, 실제 구현 관점에서는 지도 위에 상태가 다른 마커를 시각화하고, 사용자의 행동에 따라 리워드와 안내 UI가 반응하는 인터랙션 구조를 만드는 작업에 가까웠습니다.

보상 요소를 통해 유저 행동을 유도하고, 위치 정보와 카테고리 정보를 결합해 탐색 경험을 설계했다는 점에서 게임 서비스형 UX와도 연결되는 프로젝트였습니다.

구현 내용

공공데이터포털에서 대구 중구 쓰레기통 설치 현황과 폐건전지, 폐형광등 수거함 위치 데이터를 가져와 사용했습니다.

원본 데이터는 지번 주소 또는 장소 이름 형태였기 때문에, Google Geocode API를 사용해 경도와 위도 좌표로 변환한 뒤 앱에서 바로 사용할 수 있는 위치 데이터셋으로 가공했습니다.


메인화면 쓰레기통 시각화

쓰레기 카테고리

추첨공 획득

MapKit으로 생성한 지도 위에 변환된 좌표를 카테고리별로 구분해 마커로 시각화했습니다. 이를 통해 사용자는 일반 쓰레기, 건전지, 형광등 수거함을 한눈에 구분할 수 있습니다.

또한 특정 쓰레기통 위치의 마커를 클릭하면 "추첨 공"을 획득할 수 있도록 해, 단순 위치 안내를 넘어서 사용자의 행동이 보상으로 이어지는 피드백 루프를 만들었습니다.

이 구조는 지도 기반 탐색과 보상 시스템을 결합한 형태로, 서비스형 앱 안에서도 게임적인 동기 유발 요소를 설계해 본 경험이었습니다.

쓰레기통 문의

당첨결과 확인

메인 화면의 전구 아이콘을 누르면 분리배출 안내 정보를 확인할 수 있어, 탐색 화면 안에서 바로 보조 정보를 제공하는 정보형 UI 흐름을 만들었습니다.

앱에 등록되지 않은 쓰레기통이 있을 경우에는 사용자가 직접 위치를 제보할 수 있도록 구성해, 탐색 UI에서 곧바로 입력 수집으로 이어지는 흐름도 함께 설계했습니다.

매달 한 번 사용자가 모은 추첨 공을 기반으로 기프티콘 추첨을 진행했고, 이를 통해 보상 결과 확인 화면까지 포함한 리워드 루프를 완성했습니다.



결과 및 회고

공공데이터 활용 경진대회 "우수상"을 수상했습니다. 이 프로젝트를 통해 위치 기반 데이터 시각화, 사용자 위치 반영, 카테고리 분기 UI, 리워드 중심 인터랙션 설계를 함께 다뤄볼 수 있었습니다.
