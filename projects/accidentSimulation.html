건설XR: 건설현장 보조 시스템


프로젝트 개요

HoloLens 2에서 입력 처리, 사고 시뮬레이션, 런타임 추론을 직접 구현한 XR 클라이언트 프로젝트.

건설 현장에서 사고 발생 시 신속한 구조 요청은 추가 피해를 줄이는 핵심 요소입니다. 사용자의 의식 상태에 따라 시선·터치 입력으로 직접 요청하거나, 머리 움직임 기반 이상 신호를 감지해 자동 요청으로 이어지도록 구성했습니다.

  • 입력 확정 로직: 3초 dwell 입력과 시선·터치 공용 처리로 긴급 요청을 확정하는 구조 구현.
  • Ragdoll 사고 재현: 충돌·추락 이벤트에서 애니메이션 상태를 물리 상태로 전환하는 시뮬레이션 구현.
  • ONNX 런타임 통합: 머리 움직임 기반 사고 감지 모델을 Unity Barracuda로 실시간 추론.
  • 학술 검증: HCII 2023 Scopus 1저자, 3DSA 2023 우수논문상.

구현 내용

시선 입력 기반 구조 요청 인터랙션

구조 요청 입력은 시선과 터치가 동일한 처리 경로를 타도록 구성했고, 사용자는 SOS 버튼을 3초 동안 응시하거나 직접 터치해 요청을 활성화할 수 있도록 구현했습니다.

시선 입력의 흔들림과 순간적인 이탈로 오입력이 발생하지 않도록, 입력 누적 시간이 조건을 만족할 때만 다음 상태로 넘어가게 했고 진행 상황은 3단계 피드백으로 표시했습니다.

  • Scaling: 홀드 시간이 누적될수록 버튼이 점진적으로 확대됩니다.
  • Radial Fill: 배경 게이지가 함께 채워지며 현재 입력 누적량을 즉시 보여줍니다.
  • Timer: 응시 지점에 원형 타이머를 띄워 남은 시간을 숫자와 진행도로 표시합니다.


요청 완료와 수신 흐름

(1) 구조 요청자 시점

요청이 확정되면 완료 팝업을 노출하고, 3초 후 자동으로 메인 화면으로 복귀합니다.

(2) 작업 팀장 시점

구조 요청이 발생하면 요청자의 캡처된 시야 정보와 요청 상태가 수신 측 UI에 반영되도록 연결했습니다.



ragdoll 기반 사고 시뮬레이션

자동 구조 요청 기능을 검증하려면 사고 상황을 반복 가능하게 재현할 수 있는 시뮬레이션이 필요했습니다. 이를 위해 Unity의 ragdoll physics를 활용해 충돌 및 추락 이벤트에서 캐릭터가 애니메이션 상태에서 물리 상태로 전환되도록 구현했습니다.

Idle 상태의 에이전트에 충돌 감지용 콜라이더를 배치하고, 이벤트 발생 시 기본 에이전트의 관절 위치와 회전값을 ragdoll 에이전트에 전달한 뒤 상태를 교체했습니다.



사고 시나리오 재현 시스템

자재 충돌 사고 : 벽돌

자재 충돌 사고 : 파이프

자재 충돌 사고 : 철 기둥

자재 충돌 사고 : 철망 펜스

추락 사고 : 사다리

추락 사고 : 임시 발판

프로젝트에서는 자재 낙하로 인한 충돌 사고와 고층 추락 사고를 시뮬레이션으로 구현했습니다. 충돌 상황은 벽돌, 파이프, 철 기둥, 철망 펜스 4종 오브젝트를 낙하시켜 만들었고, 오브젝트별 무게를 다르게 설정해 물리 반응 차이를 주었습니다.

추락 상황은 사다리와 임시 발판 위의 에이전트에 AddForce()를 impulse 모드로 적용해 재현했고, 일반 상황은 일상 동작 애니메이션으로 구성했습니다. 이렇게 정상 상태와 위험 상태가 분리된 시나리오 세트를 구축해 이후 데이터 생성과 추론 테스트의 기반으로 사용했습니다.



데이터 생성과 추론 파이프라인

학습 데이터를 생성하기 위해 시뮬레이션의 핵심 매개변수를 실행마다 무작위로 변경하며, 사고 및 비사고 시나리오를 다양한 형태로 재구성했습니다.

  • 충돌 객체: 높이·무게·스케일을 무작위로 바꿔 다양한 충돌 패턴을 만들었습니다.
  • 에이전트: 충돌, 추락, 일반 상황 모두에서 에이전트를 Y축을 기준으로 무작위 회전시켜 배치했습니다.
  • 일반 상황 애니메이션: 재생 속도를 무작위로 조정해 평상시 데이터 변동성을 확보했습니다.

머리 움직임 데이터는 60fps 기준으로 매 프레임의 position, rotation, velocity, angular velocity 값을 추출했고, 이를 연속된 30프레임 단위 입력으로 정리했습니다.

일반 상황 역시 같은 형식으로 데이터를 생성해 학습용 샘플을 생성했습니다.


런타임 모델 통합

사고 감지 모델에는 연속된 30프레임 데이터를 입력으로 넣었고, 각 프레임은 13차원 특성 값(위치, 회전, 속도 등)으로 구성했습니다. Conv1D로 단기 패턴을 추출하고 LSTM으로 시간 흐름의 의존성을 학습하도록 결합했으며, 최종 출력은 위험 상황과 일반 상황에 대한 두 확률 값으로 구성했습니다.

학습된 모델을 ONNX 형식으로 변환한 후 Unity Barracuda에 연동하여, 시뮬레이션 환경에서 실제 추론이 수행되도록 통합했습니다.



결과

일반 상황 데이터 1000개, 사고 상황 데이터 1000개를 기준으로 학습을 진행한 결과 테스트 데이터셋 정확도 94.95%를 얻었습니다.

Unity Barracuda에 통합한 후 테스트한 결과, 구현된 시뮬레이션 안에서 충돌 사고와 추락 사고를 실제로 식별할 수 있음을 확인했습니다. 입력 처리, 피직스 기반 이벤트, 시계열 데이터 파이프라인, 런타임 추론을 하나의 흐름으로 묶어 검증한 프로젝트였습니다.
