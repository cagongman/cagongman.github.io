프로젝트 개요

테니스 동아리 전용 경기 기록 관리와 실시간 코트 현황 확인을 위한 모바일 앱

게임 프로젝트는 아니지만, 여러 사용자의 상태를 같은 화면에서 다루고 실시간으로 반영되는 리스트를 구현하며, 아이디어를 앱으로 직접 만들고 실제 운영에 적용해 본 개발 경험이었습니다.

  • 경기 기록 CRUD: 리스트 · 상세 · 수정 · 삭제가 이어지는 데이터 중심 화면 흐름.
  • 코트 현황 실시간 반영: 여러 사용자의 상태 변경이 같은 화면에 즉시 반영되는 UI.
  • Firebase 기반 인증·저장: 로그인부터 사용자 데이터 구조까지 직접 구현.

코트 현황

경기 기록 추가

Firebase를 기반으로 경기 기록과 코트 현황을 한 화면에서 확인할 수 있는 메인 화면을 구성했습니다. 코트 정보는 실시간으로 반영되도록 설계해, 여러 사용자의 상태 변화가 같은 화면에서 즉시 보이도록 구현하였습니다.

또한 로그인 사용자와 게스트 사용자의 이용 범위를 구분해, 조회는 가능하지만 기록 생성과 상태 수정은 제한되도록 흐름을 구성하였습니다.

마이페이지

메인 화면에서 경기 기록을 생성하고, 상세 화면에서 수정·삭제까지 이어지는 CRUD 흐름을 구현하였습니다. 작성자 여부와 참여자 여부에 따라 수정·삭제 권한을 구분해 실제 운영 흐름에 가깝게 구성하였습니다.


개인 통계 화면

마이페이지에서는 전체 경기 기록 중 사용자와 관련된 데이터만 다시 집계해 단식 / 복식 승률을 분리해 보여주도록 구성했습니다.



회고

이 프로젝트는 동아리 운영에 필요한 기능을 직접 떠올리고, 이를 실제로 사용할 수 있는 앱 형태로 구현해 본 경험이라는 점에서 의미가 있었습니다. 경기 기록, 코트 현황, 개인 통계를 하나의 흐름으로 연결하면서 아이디어를 기능으로 구체화하고 실제 서비스 형태로 완성해 보는 과정을 경험할 수 있었습니다.
